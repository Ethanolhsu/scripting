# 打工人日历（DayMood）

2×2 主屏幕小组件。左上角 `yyyy.MM.dd` + 星期，下面是手绘打工人和一块四字短句的小牌子。背景透明，文字/线框颜色在 App 设置页里用系统取色器选。

参考了用户给的七张截图（2026.11.30 – 12.06）的版式和情绪，插画按 Noritake / 喜茶那种“大量留白、纯黑细线、实心黑发、豆豆眼”的气质重新画，原创，没有使用 Top Widgets、Noritake 或喜茶的任何原图、水印或现成素材。`preview.jpg` 是四种状态/配色的版面示意（字体用宋体近似，真机是系统字体）。

## 状态规则

| 情况 | 短句 | 配图 |
| --- | --- | --- |
| 周一 | 自愿上班 | 瘫床 |
| 周二 | 搬砖快乐 | 搬砖 |
| 周三 | 无需打卡 | 下班 |
| 周四 | 带薪划水 | 木马 |
| 周五 | 掐点跑路 | 跑路 |
| 周六 / 周日 | 不想努力 | 躺平 |
| 法定节假日 | 带薪休假 | 沙滩 |
| 调休补班 | 被迫补班 | 桌前 |

优先级：法定节假日 / 调休补班 > 普通工作日 > 周末。`DayState.tag` 里仍保留节日名/「调休补班」，当前 2×2 版面没有画这行小字，避免和右上角的牌子挤在一起。

## 节假日从哪来

只读 App 设置页里选中的那一个系统日历，不内置节假日表：

- 只认当天覆盖的**全天事件**。
- 标题含 `补班` / `上班` / `调休` / `补课` / `值班` → 调休工作日。
- 其余全天事件 → 法定节假日，标题清理后作为节日名。
- 没选日历、没授权、当天没事件 → 退回按星期判断的工作日 / 周末。

日历权限只能在 App 里弹，小组件环境不会弹授权框。第一次安装后打开 App，点「授权并读取日历列表」，选中订阅的「中国大陆节假日」即可。

## 颜色

- 设置页 `ColorPicker` 选一个颜色，默认 `#111111`。
- 日期、星期、短句、牌子边框都跟随这个颜色。
- 插画保持黑色线稿 + 白色填充，不随颜色染色；深色壁纸上也能看清。
- 牌子底色按文字颜色亮度自动反白 / 反黑，避免白字白底。

## 透明背景

Scripting 已经支持原生透明小组件，但**不是靠代码里的 `widgetBackground` 开关**，而是添加组件时选不同的“组件种类”：

- **透明背景小组件（Transparent Background Widget）**：系统把壁纸直接垫在内容后面，真正的原生透明。要做透明效果必须加这一种。
- **普通小组件**：仍然是系统的白色/毛玻璃卡片，代码无法把它变透明；只能在 Scripting 里开「模拟透明」，本质是截一张壁纸图垫在后面。
- **模糊背景小组件**：系统模糊壁纸。

`Widget.isTransparentMode` 在透明模式（以及系统截图模式）下为 `true`，此时 `widgetBackground` 修饰符会被 Scripting 自动跳过。本组件根视图没有铺任何底色，日期、星期、插画、牌子都直接浮在系统给的背景上。

参考文档：<https://scriptingapp.github.io/guide/Widget/Widget%20API>

iOS 读不到当前壁纸亮度，做不到真正“随壁纸自动反色”，所以文字颜色交给用户在 App 里选；牌子底色会按文字亮度自动反白/反黑。

## 文件

```
DayMood/
  script.json              脚本元数据，permissions: calendar
  index.tsx                App 设置页（颜色 / 日历 / 预览）
  widget.tsx               小组件入口，约到次日 00:05 刷新
  core/settings.ts         设置默认值与颜色亮度判断
  core/store.ts            Storage 读写
  core/date.ts             本地日期、星期、次日 00:05
  core/holiday.ts          系统日历读取与状态判定
  core/dayState.ts         当天状态、短句、配图映射
  assets/lineArt.ts        八张 400×400 透明线稿（base64 内嵌）
  widget/SmallDay.tsx      2×2 版面
```

## 已知限制

- 只做 2×2 `systemSmall`，没有做中号/大号/锁屏。
- 添加时要选 Scripting 的「透明背景小组件」；选普通小组件会看到系统白卡，这不是代码能改的。
- `ColorPicker` 返回值在不同系统版本上可能是 `#RRGGBB` 或 `rgba(...)`，颜色亮度判断已兼容这两种；其他颜色名会按深色处理。
- 事件标题格式由用户的节假日日历决定，`holidayName` 只做常见的括号/日期清理，特殊命名可能显示得不够漂亮。
- 透明原生效果、日历事件标题格式尚未在真机验证；如果桌面仍是白底，先确认添加的是「透明背景小组件」而不是普通小组件。
