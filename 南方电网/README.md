# scripting南方电网

用于 Scripting App 的南方电网 iOS 脚本，包含扫码登录、账户同步、电费与用电数据、小组件配置和本地电价图片识别。

当前版本：`1.2.2`

## 功能

- 微信与南网在线扫码授权
- 绑定缴费户号同步
- 电费余额、本月用电、本月账单、上月账单和昨日用电
- 多接口账单降级、响应字段兼容与缺失数据缓存恢复
- 账单接口采用 6 小时冷却，余额和用电保持约 3 小时刷新
- 经典版中号小组件四个可配置数据位
- 青绿玻璃版中号小组件三个可配置数据位
- 冰川小号阶梯仪表与深浅外观
- 阶梯看板中号小组件与可导入、管理的渐变配色
- iOS 原生分组设置界面和紧凑型小组件配置页
- 本地图片 OCR 电价识别与手动录入

## 使用

将 `scripts/南方电网` 目录放入 Scripting 项目的脚本目录，通过 Scripting App 运行 `index.tsx`，并使用 `widget.tsx` 渲染桌面小组件。

本地验证：

```powershell
npm install
npm test
npm run typecheck
```

原生界面、扫码授权、网络请求和小组件必须在 iPhone 的 Scripting App 中验证。

## 隐私

仓库不包含真实缴费户号、客户姓名、地址、使用地区、登录令牌、二维码、账单缓存、设备日志、截图或局域网连接信息。

登录令牌、绑定账户和小组件数据由 Scripting App 在用户设备本地保存。请勿提交运行日志、导出的 Storage 数据、二维码图片或带有账户信息的截图。
