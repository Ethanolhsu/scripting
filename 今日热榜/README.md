# 今日热榜 · Scripting App 版

把原 Scriptable 项目「今日热榜」（`Scriptable/今日热榜.js` + 依赖 `_LSP.js`）移植到 [Scripting App](https://apps.apple.com/app/id6479691128) 的小组件项目。

原版靠 Scriptable 的 `ListWidget` 和 `_LSP` 框架画组件、用 WebView 打开网页做设置；Scripting 是 TSX + SwiftUI 体系，所以这里是按它的组件模型重写，不是改几行就能跑。数据抓取、页面解析、榜单管理、配色/条数/行距这些原始功能都保留了。

## 目录结构

```
今日热榜-Scripting/
├─ index.tsx    # 设置页（App 内运行）：管理榜单、条数、字号、配色
├─ widget.tsx   # 小组件入口：抓取 + 渲染，必须在桌面组件里运行
├─ shared.ts    # 公共模块：网络、解析、缓存、设置读写
└─ README.md
```

文件名不能改：`index.tsx` 是脚本主入口，`widget.tsx` 是小组件入口。

## 安装

1. 在 Scripting App 里新建一个脚本，命名「今日热榜」。
2. 把 `index.tsx`、`widget.tsx`、`shared.ts` 三个文件放进这个脚本（在脚本里新建同名文件后粘贴内容即可，也可以从「文件」App 导入 `.tsx`）。
3. 先运行一次 `index.tsx`（脚本主入口），确认设置页能打开。
4. 回到桌面：长按空白处 → 加号 → 找到 Scripting → 选一个小/中/大号组件 → 长按组件点「编辑组件」→ 选择「今日热榜」这个脚本。

组件支持自定义参数（Parameter）：

- 留空：每次组件刷新时，按设置页里的榜单顺序轮换显示（和原版一样）。
- 填榜单名（如 `微博`、`知乎`、`抖音`）：这个组件固定显示匹配到的榜单。
- 填榜单 ID（如 `KqndgxeLl9`）也可以。

## 设置页能改什么

- **已添加的榜单**：显示/移除。
- **添加榜单**：粘贴 `https://tophub.today/n/xxx` 链接或 8~12 位 ID，脚本会去取一次页面，拿到榜单名和图标后存下来。
- **常用榜单**：内置 11 个榜单（微博、知乎、百度、抖音、B站、贴吧、虎扑、36氪、少数派、IT之家、GitHub），一键添加。
- **条数**：小/中/大尺寸分别设置（默认 5 / 5 / 12）。
- **字号与行距**：榜单名字号、正文与序号字号、行距。
- **配色**：前三名序号色、榜单名颜色、正文颜色，填 `#RRGGBB`；留空用系统语义色，自动适配浅色/深色。
- **开关**：是否显示榜单名与图标、是否显示刷新时间（中/大尺寸）。

设置、榜单、页面缓存和图标都写在 App Group 的 `Documents/今日热榜/` 下，所以 App 内改完，桌面组件读得到。设置页还有「刷新所有组件」按钮。

## 和原版的对应关系

| 原版（Scriptable） | 这里（Scripting） |
| --- | --- |
| `_LSP.js` 的 ListWidget 组件 | `widget.tsx` 里用 VStack / HStack / Text / Image 组合 |
| WebView 打开 `manage` 网页做设置 | `index.tsx` 原生列表设置页 |
| FileManager + Keychain 存配置 | App Group 下 `settings.json` |
| 组件轮换索引 | 同一个 settings 里的 `cursor`，每次刷新 +1 |
| 前三名红色斜体 | `italic` + `#EF233C` |
| 图标要带 Referer 才给图 | 先用 fetch 下载到本地，再用 `Image filePath` 显示 |
| 页面 HTML 正则解析 | 原正则照搬，另加电脑版 UA 兜底 |

## 已知限制

- **站点安全验证**：tophub.today 现在会对非浏览器请求做「安全验证」拦截（返回 403 页面）。脚本已经做了两件事：换电脑版 UA 再试一次；失败时退回上一次成功缓存。如果一直显示「暂无数据，检查网络后刷新」，换 Wi-Fi/蜂窝网络或隔一段时间再试，原版遇到同样拦截也取不到数据。
- **单条点击跳转**：现在整块组件点击会打开当前榜单的网页（`widgetURL`）。原版是每条热搜跳到各自链接，这需要 Scripting 的 `Link` 视图支持，等它稳定后再补。
- **刷新频率**：组件每次渲染时请求 `after 60 分钟` 刷新，iOS 会按自己的预算节流，实际不一定准点。同一榜单 10 分钟内直接读缓存。
- **没有在线搜榜**：原版设置页里的 WebView 搜索依赖登录态，这里改成「粘贴链接/ID」+「常用榜单」。
- 组件渲染有约 30MB 内存限制，条数别设太大（大尺寸 12 条左右比较稳）。

## 排查

- 组件空白/报错：先在 App 里运行 `index.tsx` 看能不能正常打开，再运行一次 `widget.tsx` 看控制台报错。
- 图标不显示：图床 `file.ipadown.com` 有 Referer 校验，脚本下载失败时会自动省略图标，不影响文字。
- 想清空数据：删掉 App Group 里 `今日热榜` 目录，或在设置页移除全部榜单。
